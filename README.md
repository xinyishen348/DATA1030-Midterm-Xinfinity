# DATA1030 Midterm Project - Xinfinity

This repository contains the work for our DATA1030 midterm project.

## Repository Structure

- `data/`: raw and processed data
- `figures/`: figures generated for the project
- `results/`: model predictions and results
- `report/`: project report and presentation materials
- `src/`: source code and notebooks

## Environment

- pandas 3.0.3
- Matplotlib 3.11.0
- seaborn 0.13.2
- scikit-learn 1.9.0
